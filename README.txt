ClickGUI — мод для Minecraft 1.21.11 (Fabric)

Как собрать:
1. Установите JDK 21: https://adoptium.net/ (отметьте "Set JAVA_HOME" и "Add to PATH").
2. Распакуйте архив в папку без русских букв в пути, например C:\mods\clickgui.
3. Запустите build.bat. Первый раз долго (5-10 мин), нужен интернет.
4. Готовый .jar появится в папке out.
5. Положите его в .minecraft\mods вместе с Fabric API для 1.21.11.

В игре: правый Shift открывает меню.


Фон меню: src/main/resources/assets/clickgui/textures/gui/background.png (1600x900). Замените файл своим PNG того же размера и пересоберите.
